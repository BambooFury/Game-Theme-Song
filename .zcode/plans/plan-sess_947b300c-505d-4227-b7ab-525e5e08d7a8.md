## Шаг 2: Расширить engine.ts — экспортировать контекст текущей игры

Добавить новые экспорты в `frontend/core/engine.ts`:

- `getCurrentGameName(): string | null` — возвращает `currentGameName`
- `getCurrentTitle(): string | null` — возвращает `currentTitle`
- `subscribeContext(fn): () => void` — подписка на изменения контекста (game name, title, mode, appId). Внутренняя функция `setContext()` будет вызывать listeners при изменениях в `playForApp`, `runReroll`, `setToast`, `pollOnce`.
- `isPlaying(): boolean` — возвращает `audioEl != null && !audioEl.paused`
- `subscribePlayback(fn): () => void` — подписка на play/pause события
- Убрать `setToast('searching')` из `playForApp` и `rerollCurrent` (toast больше не нужен)
- Убрать `setToast('ready')` — toast больше не используется для показа
- Оставить `ToastMode`/`ToastState`/`subscribeToast`/`getToast` для внутреннего использования, но `SearchToast.tsx` больше не будет показывать toaster/ConfirmModal

## Шаг 3: Создать `frontend/core/GamePageButton.tsx` — кнопка ноты на странице игры

Использует `routerHook.addPatch('/library/app', patch)` паттерн (как AutoSleep):

```tsx
// GamePageButtonHost — рендерится внутри дерева страницы через addPatch
// Содержит кнопку с MdMusicNote иконкой
// При клике открывает popup-окно через openManagerPopup('main')
// Показывает индикатор если музыка играет (зелёная точка)
```

Кнопка стилизована как compact round button (как Auto-Claim toolbar button):
- `width: 34px, height: 34px, borderRadius: 50%`
- `background: transparent`, hover `rgba(255,255,255,0.2)`
- `color: var(--main-text-color, inherit)`
- `-webkit-app-region: no-drag`

## Шаг 4: Создать `frontend/core/MainPopup.tsx` — popup с двумя секциями

Структура (по паттерну Auto-Claim `ManagerWindow`):
- `SteamDialog` с `strTitle="Game Theme Song"`, `resizable`, `saveDimensionsKey="gtsMainPopup"`
- `popupWidth={520}`, `popupHeight={Math.round(window.innerHeight * 0.7)}`
- Сверху ряд tab-кнопок (`DialogButton`):
  - **Now Playing** — активная по умолчанию, иконка `MdMusicNote`
  - **Settings** — иконка `MdSettings`

### Секция "Now Playing"
Показывает контекст текущей игры (данные из engine):
- **Game name** (или "No game open")
- **Track title** (или "Searching..." / "No theme found")
- Кнопка **Skip** (reroll) — `DialogButtonSecondary`, иконка `MdSkipNext`, вызывает `rerollCurrent()`
- Кнопка **Stop** — `DialogButtonSecondary`, иконка `MdStop`, вызывает `stopAudio(0.5)`
- Кнопка **Keep** (accept) — `DialogButton`, вызывает `acceptCurrent()`
- Индикатор: играет/поиск/не найдено
- Прогресс-бар воспроизведения (из `getAudioEl().currentTime / duration`) — опционально, `ProgressBar` из millennium

### Секция "Settings"
Перенос всех настроек из `SettingsContent.tsx`:
- Custom game music (ButtonItem → openManagerPopup('library'))
- Music volume (SliderField)
- Song length limit (SliderField)
- Loop song (ToggleField)
- Manual song search (ToggleField)
- Keep songs only after ✓ (ToggleField)
- Stop on game launch (ToggleField)
- Downloaded music (ButtonItem → openManagerPopup('cache'))
