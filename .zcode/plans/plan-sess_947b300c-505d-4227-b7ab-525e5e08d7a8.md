# План: 9 исправлений

## 1. Починить кнопку ноты (стилизация)
**Проблема:** `replaceChild` уничтожает внутреннюю структуру Steam-кнопки, react-icons рендерится без Steam-классов → прозрачный фон, другой вид.

**Решение:** Вернуться к паттерну старой версии — сохранить `btn.firstChild` (Steam inner span) и только заменить его `innerHTML` на SVG-строку с `class="SVGIcon_Settings"` и `fill="currentColor"`. Не использовать react-icons для кнопки (она инъектируется через DOM, не через React).

**Файл:** `frontend/core/GamePageButton.tsx`

## 2. Попап сначала синий, потом тёмный (5 сек)
**Проблема:** SteamDialog не применяет тёмную тему сразу — ждёт асинхронной загрузки SteamUI CSS.

**Решение:** В `ManagerWindows.tsx` при монтировании popup добавить CSS-класс тёмной темы на document popup-окна. Auto-Claim не делает этого явно — его окно тоже может иметь эту проблему, но использует `ModalRoot` который наследует тему. Проверю, можно ли добавить `className` или `bDarkTheme` пропс к `GenericDialog`. Если нет — инъектировать CSS-переменные SteamUI сразу при открытии.

**Файл:** `frontend/core/SteamDialog.tsx` или `frontend/core/ManagerWindows.tsx`

## 3. Настройки не сохраняются после перезапуска
**Проблема:** Все JSON-файлы (settings.json, cache.json, custom.json, ignored.json) лежат внутри PLUGIN_DIR. Starlight V2 при переустановке/обновлении стирает плагин-директорию.

**Решение:** Как в Auto-Claim — создать `DATA_DIR = millennium.get_install_path() .. "/plugins/game-theme-song-data"` (sibling-папка). Перенести туда CACHE_FILE, CONFIG_FILE, CUSTOM_FILE, IGNORE_FILE, RESOLVE_MARKER, BOOT_MARKER. Добавить миграцию: если файлы есть в PLUGIN_DIR, но нет в DATA_DIR — скопировать.

**Файл:** `backend/main.lua`

## 4. Кнопка появляется с задержкой 2-3 сек
**Проблема:** `setTimeout(tryInject, 2000)` + `setInterval(tryInject, 3000)` — polling вместо event-driven подхода.

**Решение:** Использовать `Millennium.findElement(doc, selector, timeout)` (await) в `injectButton` вместо синхронного `doc.querySelector`. Убрать `setInterval`. Полагаться на `finished-request` event + `MutationObserver` как в старой версии.

**Файл:** `frontend/core/GamePageButton.tsx`
