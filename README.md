# Game Theme Song

A [Millennium](https://github.com/SteamClientHomebrew/Millennium) plugin that plays each game's theme music in the background when you open it in your Steam library.

## Features

- Auto-plays a theme track when you open a game page, fades smoothly between games.
- One-knob settings panel: a music volume slider (0–100%, 1% precision).
- Local cache so repeat visits start instantly.
